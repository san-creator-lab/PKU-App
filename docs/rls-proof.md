`supabase/migrations/` are applied to a scratch PostgreSQL 16 database
under `scripts/db/harness.sql` (Supabase-compatible roles, `auth.uid()`
reading `request.jwt.claims`, realtime publication, storage stubs) and
every cross-family access below is executed exactly as PostgREST would
run it. `psql` echoes each statement; DENIED/0-row results are asserted.
